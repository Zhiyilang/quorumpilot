QuorumPilot

A model may speak. It may not be believed.

A multi-agent risk-review system for trading. Four specialist agents review a proposed trade — but a deterministic verifier decides which of their claims count, and a pure-arithmetic arbiter decides the verdict. No model touches the final number.

支一郎 · solo developer · MIT · offline-deterministic · 137 assertions
The problem

One confident hallucination is the entire loss

  • Ask a language model whether a trade is safe: it answers fluently — with numbers it invented.
  • In a risk decision, that fluency is exactly what makes it dangerous.
  • So the agents here may propose anything — but nothing counts until it is proven.
The part that matters

Evidence, not eloquence

  • Every claim must cite a field in the computed facts.
  • A deterministic verifier re-resolves each citation — an agent's word is not evidence.
  • Anything unprovable loses its voting weight entirely.
  • The arbiter is pure arithmetic: no model touches the final number.
Live demo · real run

Risky trade → REJECT, seven breaches, each with its number

$ python -m quorumpilot review examples/proposal_risky.json QuorumPilot verdict=REJECT score=-55 brain=offline-deterministic long GBPUSD 500000 units | risk 10.00% of equity (USD 2500.00) claims: 16 verified, 0 dropped breaches: - RISK_PER_TRADE: 10.00% of equity exceeds the 2.00% cap - TOTAL_RISK: open + proposed 13.60% exceeds the 6.00% portfolio cap - LEVERAGE: effective 25.3x exceeds the 20.0x cap - RISK_CONCENTRATION: 10.00% of equity above the 4.00% single-name cap ... 7 rules breached

Not just a no-machine: a clean proposal returns PROCEED, a borderline one PROCEED_WITH_CAUTION with its reasons.

Adversarial · 137 offline assertions

A quorum handed a brain that fabricates: verdict unchanged

$ python eval.py ... lying agent / liar's claims ... verdict is unchanged ... 137 passed, 0 failed

An agent that fabricates three confident claims has all of them dropped; the verdict is identical to the honest run. The system cannot be talked out of the arithmetic.

Explainability & ingestion

The whole argument, re-runnable line by line

explain

Full arbitration transcript: every specialist, every citation, every objection and its voting weight — inspectable, not a black box.

ingest

Five files, four formats, three naming schemes — merged with provenance. Conflicts are reported, never silently picked.
Interoperable

$ python -m quorumpilot mcp < examples/mcp_handshake.jsonl protocolVersion ... serverInfo ... tools ... review_trade ...

Six tools over MCP; responses never sliced into invalid JSON. Any MCP host can call the reviewer before a trade executes.
